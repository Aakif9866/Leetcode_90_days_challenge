## 👋 Why This Challenge?

This repository is my commitment to spending the next 90 days revising DSA and becoming a better problem solver.

The objective isn't simply to increase the number of problems solved. It's to revisit fundamental concepts, recognize patterns, understand different approaches, learn from mistakes, and become more confident when approaching unfamiliar problems.

I'm using this challenge as an opportunity to strengthen my foundations through consistent, hands-on practice.

**The plan is simple:**

- 🎯 Solve **2–3 LeetCode problems every day**.
- 💻 Write every solution in **C++**.
- 🧠 Understand the approach, not just the accepted answer.
- 🔍 Review mistakes, edge cases, time complexity, and space complexity.
- 📝 Maintain a daily record of problems solved and lessons learned.
- 📈 Track progress through GitHub commits throughout the challenge.

No shortcuts. No chasing streaks without understanding. Just consistent effort and measurable improvement.

`problem-number-problem-name.cpp`

- `01-contains-duplicate.cpp`

## 🚀 Day 01 — Getting Started

**Date:** October 10, 2026

Started with three problems covering duplicate detection, Sudoku validation, and array manipulation.

|  #  | Problem                                                                                     | Key Concepts                        | Status |
| :-: | :------------------------------------------------------------------------------------------ | :---------------------------------- | :----: |
| 01  | [Contains Duplicate](https://leetcode.com/problems/contains-duplicate/)                     | Arrays, Hash Sets                   |   ✅   |
| 02  | [Valid Sudoku](https://leetcode.com/problems/valid-sudoku/)                                 | Hash Sets, Rows, Columns, 3×3 Boxes |   ✅   |
| 03  | [Product of Array Except Self](https://leetcode.com/problems/product-of-array-except-self/) | Prefix and Suffix Products          |   ✅   |

### Key Takeaways

- **Contains Duplicate:** Use a set to detect repeated values efficiently.
- **Valid Sudoku:** Validate rows, columns, and 3×3 boxes independently while ignoring empty cells. Pay attention to variable scope when maintaining a set.
- **Product of Array Except Self:** Understand how prefix and suffix products can produce the required result without repeatedly multiplying every other element.

The goal is to revisit these concepts until the underlying patterns become intuitive, rather than merely remembering individual solutions.

## 🧠 How I Approach Each Problem

My intended workflow for every problem is:

1. **Understand** — Read the problem carefully and identify constraints and edge cases.
2. **Attempt** — Develop a solution independently before looking for alternatives.
3. **Implement** — Write a clean C++ solution.
4. **Analyze** — Evaluate time and space complexity.
5. **Review** — Identify mistakes, missed edge cases, or a more efficient approach.
6. **Record** — Document the key takeaway in the day's notes.
7. **Revisit** — Return to important problems when revising the relevant pattern.

An accepted submission is a milestone, but understanding _why it works_ is the real objective.
